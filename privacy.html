Privacy policy

Updated 28 September 2026

CodexNata gws is a personal desktop integration maintained by Jekudy for its account owner and personally known users. This policy covers the integration and this informational website.

Data access and purpose

With the owner's Google consent, the integration can access the account's basic identity and the Google services required for requested tasks:

  • Drive files, Docs, Sheets, Slides, Forms and responses, and file activity;
  • Gmail messages, attachments, drafts, labels and basic mail settings;
  • Calendars and events, contacts including other contacts, and task lists;
  • Available Meet spaces and meeting information, and Apps Script projects and deployments.

Data is used to answer the owner's requests and perform their authorized actions, such as organizing files, editing documents or sending a requested message. Actual access depends on the permissions granted and Google account capabilities.

Processing and sharing

Google Workspace CLI runs on the owner's computer and communicates with Google APIs. When an AI assistant handles a task, relevant API results and task content may be sent to that assistant's provider, including OpenAI when Codex is used. Such content may appear in conversation history and local outputs. The owner controls the assistant account, its data settings and which tasks to request.

The integration does not sell Google user data, use it for advertising, or intentionally use it to train general-purpose AI models. Google-derived data must only be sent to an AI service configured for processing consistent with Google's API user-data rules. This policy does not override an external provider's retention rules or account settings.

Storage and protection

In the configured local OAuth flow, gws stores its refresh credentials encrypted on the computer, using a key protected by the operating system. OAuth client configuration is stored locally. Credentials are not included in this website or its public source repository.

Task outputs, exported files and conversation history can contain Google data. They remain until deleted by the owner or the applicable provider's retention process. The integration has no separate public server or central database of Google account data.

Retention, deletion and revocation

Local credentials are retained while the connection is in use. You can revoke CodexNata gws in your Google Account connections. Revocation stops future API access; it does not delete previously created files, messages, local exports or assistant history.

To remove retained copies, delete the relevant local outputs and credentials and use the assistant provider's history or deletion controls. Contact the maintainer through the Jekudy GitHub profile for help. Do not include private account data or credentials in a public issue.

This website

This is a static informational site hosted by GitHub Pages. It has no account sign-in, analytics scripts, forms or application cookies. GitHub may process network request data, including IP addresses, to operate and secure hosting, as described in the GitHub Privacy Statement.

Google API Services User Data Policy

CodexNata gws's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

Updates will be published on this page with a revised date. Material changes to data use require appropriate notice and, where required, renewed consent.
